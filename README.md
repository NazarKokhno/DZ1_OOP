# Student Class (C++)

A simple C++ project for practicing Object-Oriented Programming (OOP).

## Features

- Store student information
- Constructors for object initialization
- Getters and setters
- Input and output of student data
- Access control for reading and modifying information

## Student Information

| Field | Description |
|:---|:---|
| `FullName` | Full name |
| `DateOfBirth` | Date of birth |
| `Contact` | Phone number |
| `City` | City of residence |
| `Country` | Country of residence |
| `EduInstitution` | Educational institution |
| `GroupNum` | Group number |

## Concepts Used

- Classes and objects
- Encapsulation
- Constructors
- Getters and setters
- Member functions

## Technologies

- C++
